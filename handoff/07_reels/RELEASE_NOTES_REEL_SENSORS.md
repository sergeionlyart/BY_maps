# Рилс R-V1 «Второй сенсор» (INF-22) — v1.0.0

Дата: 2026-10-04. Формат 1080×1920, 30 к/с, 40 с, RU и BE.
Сцена: `tools/reel_sensors_scene.json`; рендер: `tools/render_reel_sensors.py`
(примитивы R-P1 импортируются из `tools/render_reel_pension.py`); тесты —
`etl/tests/test_sensors_reel.py` (14).

## Сцены

| Время | Сцена | Что в кадре |
|---|---|---|
| 0–4 с | intro | бренд, силуэт страны, заголовок |
| 4–10 с | hook | «109 районов из 117: знак изменения доли совпал», ρ = 0,79 |
| 10–18 с | scatterH1 | статистика против спутника, 1990–2020: точки появляются, ρ |
| 18–27 с | refuted | **опровержение H2**: «Мы ошиблись — и это результат», облако без наклона, ρ = −0,13 |
| 27–35 с | map | карта «свет минус население» 2013–2019, счётчик 65 из 118 |
| 35–40 с | finale | «Свет показывает, где люди живут, но не куда они уходят», адрес раздела |

Все числа в кадре вычисляются из `web/public/data/sensors.json`; тест
запрещает вписанные руками числа в текстах сцены, сверяет счётчики с
опубликованными, шкалу карты — со страницей и проверяет безопасную зону 4:5 на
кадрах шести сцен в обоих языках. Оси рассеяний — в одном масштабе по X и Y
(разброс света и населения сравнивается честно); за пределами осей точки
прижимаются к краю — в H1 это одна точка по оси спутника.

## Найдено на превью и исправлено

- Облако H2 обрезалось сверху: изменения доли в свете шире ±0,6 лог-единицы —
  пределы осей заданы отдельно для H1 и H2, в одном масштабе по обеим осям.
- Засечки вида «+49 %», «−33 %» (перевод круглых лог-значений) плохо
  читались — засечки теперь по круглым процентам (−50, 0, +50, +100 %).

## Не сделано

- **Релиз на GitHub** с каноническими CBR-мастерами (`artifact-sensors-reel-v1.0.0`)
  не создан: в этой сессии нет инструмента создания релизов.
- Публикация в соцсетях — вне рамок.

## Пересборка

```bash
FFMPEG=/path/to/ffmpeg-with-libx264 .venv/bin/python tools/render_reel_sensors.py --lang all
# превью без видео: --dump-every 30
# веб-версия: ffmpeg -i build/reel_sensors_ru.mp4 -c:v libx264 -preset slow -crf 18 \
#             -pix_fmt yuv420p -movflags +faststart -an web/public/video/reel_sensors_ru.mp4
```
