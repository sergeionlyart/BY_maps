# Очередь сдачи INF-13 / INF-15

Служебный журнал очереди сдачи в `master` (раздел 10 обоих ТЗ). Правила:

- Сдача — по одной за раз, через замок `handoff/09_next_research/LOCKS/merge.lock`
  (содержимое: `<INF-код> <ISO-время захвата> <PR#ии-номер коммита>`). Просрочка
  замка — 45 минут; после просрочки следующая группа занимает очередь и
  записывает это ниже.
- Мерж — squash, сообщение коммита `INF-13 <WP>: <суть>` / `INF-15 <WP>: <суть>`.
- После каждого мержа — запись строкой в таблицу ниже (сама группа, вручную).
- Общие файлы — только `append` с маркерами `/* INF-13 BEGIN */ … /* INF-13 END */`
  или `/* INF-15 BEGIN */ … /* INF-15 END */`. При коллизии (обе группы задели
  один файл) — сохраняются оба блока, порядок по номеру исследования (INF-13
  выше INF-15).
- Публикация (деплой) — свой отдельный замок `LOCKS/deploy.lock`, таймаут 30
  минут; не путать с замком сдачи.
