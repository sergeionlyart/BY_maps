# План очистки истории Git

Этот план применяется только после отдельного согласования на переписывание
истории и `force push`. Он нужен для удаления локальных путей и неутверждённой
commit-метаинформации, обнаруженных в старых коммитах.

1. Зафиксировать список затронутых refs, SHA и типов данных в приватном
   отчёте, не копируя значения секретов или персональных контактов.
2. Создать независимый mirror-backup и уведомить всех пользователей, что SHA
   изменятся.
3. В зеркальной копии применить `git filter-repo`: удалить или заменить
   только подтверждённые пути, а неутверждённый email в author/committer
   metadata заменить на GitHub noreply-адрес владельца. Храните исходное
   значение только в локальной переменной, не в shell history и не в скрипте.
4. Выполнить `git fsck --full`, `./tools/security-scan.sh` и выборочную
   проверку прежних SHA/файлов в переписанной истории.
5. После независимой проверки выполнить согласованный `force push --mirror`,
   обновить теги и попросить участников заново клонировать репозиторий либо
   безопасно синхронизировать их forks.
6. Проверить GitHub Releases, Actions artifacts/logs, Issues, PR и Vercel;
   Git history rewrite не удаляет автоматически уже опубликованные копии.
