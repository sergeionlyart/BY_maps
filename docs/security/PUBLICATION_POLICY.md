# Правила публикации материалов

## Можно публиковать

- исходные исследовательские данные и производные наборы, если источник и
  лицензия позволяют публикацию;
- сохранённые копии общедоступных источников, URL, хэши и методологию;
- код ETL, расчёты, тесты, воспроизводимые артефакты и инструкции;
- публично утверждённые данные авторской страницы.

## Нельзя коммитить

- ключи, токены, пароли, cookies, заголовки авторизации, приватные URL и
  файлы учётных данных;
- `.env` и локальные конфигурации сервисов, IDE, агентов, MCP и Vercel;
- приватные документы, переписку, промпты, scratchpad-файлы, дампы, логи и
  диагностические выводы;
- неутверждённые персональные данные, имена локальных пользователей,
  устройств, абсолютные рабочие пути и внутренние сетевые адреса.

## Проверка перед публикацией

1. Для каждого нового файла подтвердите, что он относится к публичной
   исследовательской цели.
2. Для снимков сторонних страниц и архивов проверьте встроенные метаданные,
   параметры URL, служебные сетевые комментарии и случайно сохранённые
   учётные данные.
3. Запустите `./tools/security-scan.sh`; результат сканера классифицируйте,
   а не подавляйте без объяснения.
4. Подтверждённый секрет сначала отзовите или ротируйте, затем удаляйте из
   текущего дерева и истории. Не копируйте значение в Issue, PR или commit.
