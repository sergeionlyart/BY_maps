# INF-22 «Второй сенсор» — проверяемый пакет v1.0.0

Сверка официальной численности 118 районов Беларуси с двумя физически
разными датчиками: спутниковой раскладкой населения по застройке
**GHS-POP R2023A** (1975–2020) и **ночными огнями** DMSP + VIIRS (1992–2024).
Все сравнения — по долям района в национальном итоге того же датчика.

Лендинг: https://by-population-maps.vercel.app/research/sensors

## Главное

| Гипотеза (заморожена до расчёта) | Порог | Результат | Вердикт |
|---|---|---|---|
| H1: статистика и спутник согласны в изменениях долей, 1990→2020 | ρ ≥ 0,60 | ρ = 0,7895, n = 117; 2000→2020 ρ = 0,9056; знак совпал в 109 из 117 | **подтверждена** |
| H2: доля в свете следует за долей в населении, 2013→2019 | ρ ≥ 0,40 | ρ = −0,132, p = 0,15; DMSP 1992→2011 ρ = −0,176 | **опровергнута** |
| H3: расхождение «статистика − спутник» растёт с удалённостью от облцентра | ρ ≥ 0,25, p < 0,05 | ρ = 0,030, p = 0,75 | **опровергнута** |
| H4: после 2021 свет расходится со статистикой сильнее | отношение ≥ 1,25 | 1,193 | **опровергнута** |

Пост-хок (помечен, ничего не подтверждает): по **уровням** свет и население
согласны (ρ = 0,85–0,87 в 2013, 2019, 2024), по **изменениям** — нет: в 65
районах из 118 доля в свете за 2013→2019 росла, а доля в населении падала;
медианный район: население −5,9 %, свет +10,7 %.

## Запуск

```bash
bash code/run.sh   # Python >= 3.10, только стандартная библиотека, сеть не нужна
```

Финал: `Все 30 контрольных метрик воспроизведены в допусках.`

## Состав

- `etl/sensors.py` — весь расчёт; `etl/common.py` — пути пакета.
- Входы: `data/raw/grid/reconciliation.csv` (официальный ряд на эпохах GHS и
  `grid_sum`, INF-15), `web/public/data/nightlights_v2.json` (доли света,
  INF-08), `data/raw/nightlights/zonal_vnl.csv` (сырые радиансы VIIRS для
  сверки), `web/public/data/data.json` (годовой официальный ряд),
  `data/curated/travel_times.csv` (INF-04). sha256 — `sources/registry.csv`.
- Выходы: `web/public/data/sensors.json` (всё, что на странице),
  `data/curated/sensors.csv` (таблица 118 районов),
  `data/final/computed_results.json` (30 контрольных метрик).
- `PREREGISTRATION.md` — гипотезы, пороги, окна, гейты; одна датированная
  поправка до расчёта. `METHODS.md` — методблок с лендинга.
- `claims.yaml` — реестр утверждений с типами DATA/CALC/INTERPRETATION/
  LIMITATION/POSTHOC.
