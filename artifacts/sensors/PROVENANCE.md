# Происхождение данных и шагов

1. **Входы** (все завендорены в репозитории проекта, внешних выгрузок нет):
   `reconciliation.csv` (INF-15: официальный ряд на эпохах GHS-POP и сумма
   GHS-POP R2023A по полигонам районов), `nightlights_v2.json` (INF-08:
   гармонизированные доли DMSP + VIIRS), `zonal_vnl.csv` (INF-08: сырые
   зональные радиансы VIIRS), `data.json` (база проекта), `travel_times.csv`
   (INF-04). sha256 каждого — `sources/registry.csv`.
2. **Пререгистрация** заморожена коммитом `a90d5e7` **до** первого расчёта
   (проверяемо по истории git: `etl/sensors.py` появился позже).
3. **Поправка 1** (коммит `2236c51`, тоже до расчёта): у Дрибинского района
   нет официального ряда до 1991 года, окно 1990→2020 считается по 117
   районам, доли обоих датчиков — по одному набору зон.
4. **Расчёт** — `python -m etl.sensors`, детерминирован, случайности нет.
5. **Пост-хок** (почему H2 опровергнута) выполнен после получения данных и
   помечен так в выходном JSON, на странице и здесь.
