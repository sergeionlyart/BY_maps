# Changelog пакета sensors

## v1.0.0 — 2026-10-04

Первый релиз INF-21: сверка официальной численности 118 районов с GHS-POP
R2023A (1975–2020) и ночными огнями DMSP + VIIRS (1992–2024) по долям в
национальном итоге каждого датчика. H1 подтверждена (ρ = 0,79), H2–H4
опровергнуты; помеченный пост-хок «уровни согласны, изменения — нет»; пять
вычислимых гейтов пройдены; одна датированная поправка к пререгистрации до
расчёта. 30 контрольных метрик.
