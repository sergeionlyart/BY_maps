# Changelog пакета seam

## v1.0.0 — 2026-10-04

Первый релиз. Таблица из 234 491 ячейки 1 км в полосе ±52 км вокруг пяти
границ Беларуси; локальная линейная разрывная регрессия по 16 исходам
(застройка WSF и GHSL, огни Li et al. DMSP и VIIRS-ряд, огни VIIRS VNL при
равной застройке, пашня GLAD, уровни) на каждом из пяти участков; основная
спецификация по пререгистрации плюс проверки устойчивости — всего 660 оценок.

Вердикты по правилам пререгистрации: H1 — не подтверждена, H2 — не
подтверждена, H3 — не подтверждена, H4 — подтверждена; H5 (официальное
население 213 единиц в полосе, описательно) — подтверждена.

34 контрольные метрики: 18 ключевых τ (пашня 2003→2019 на всех участках,
уровень пашни 2019 у России и Украины, огни 2019→2024 на украинском участке,
рост застройки WSF и огни при равной застройке на всех участках) с допуском
±0,001; медианы темпа населения H5 по пяти участкам (сосед и Беларусь) с
допуском ±0,01; число ячеек и пять вердиктов — точно.

Проверки, добавленные после фиксации пререгистрации (подучастки 1°×1°,
ложные границы ±30 км, бублик 10 км для DMSP, контроль только застройкой для
исхода I), помечены `added = 1` и на вердикты не влияют.
