# Шов на карте: Беларусь и соседи по обе стороны границы

Проверяемый пакет артефактов v1.0.0 исследования INF-20 `seam` проекта
«Население Беларуси, 1897–2026».

## Исследовательский вопрос и главный вывод

Видна ли государственная граница Беларуси из космоса? Граница с каждым из
пяти соседей идёт по одинаковому ландшафту, а правила различаются с 1991 года.
Если у самой линии есть скачок, его создала не география. Мы разбили полосу
±50 км вокруг всех пяти границ на 234 491 квадрат 1 км и оценили разрыв
(локальная линейная разрывная регрессия, τ = сосед минус Беларусь у линии) в
росте застройки, ночных огнях и доле пашни.

**Вывод: государство оставило шов в полях, а не в домах и не в огнях.**
За 2003→2019 доля пашни у самой линии выросла быстрее белорусской на
литовской (+13,4 п.п.) и латвийской (+6,9 п.п.) сторонах и упала на
российской (−5,1 п.п.); на польской (+0,3) и украинской (−1,9) разница
незначима. Значимого скачка в росте застройки WSF 1990→2015 нет ни на одной
границе; яркость огней при равной застройке (H3) тоже не отличается. Огни
2019→2024 на украинском участке упали на −0,27 лог. пункта относительно
белорусской стороны — это война. Из четырёх формальных гипотез,
записанных до расчёта, подтвердилась одна (H4); H1–H3 не подтверждены.

Официальная статистика (H5, описательно, 213 единиц в полосе 0–50 км)
согласуется с ожиданием: литовские и латвийские единицы теряют население
быстрее белорусских районов напротив (медиана −1,9 и −2,1 %/год против −1,4
и −1,6), польские гмины — медленнее (−0,7 против −0,9); российские районы —
практически так же (−1,73 против −1,68), украинские — медленнее (−0,85
против −1,10). Определения населения у стран различаются.

## Как воспроизвести

Требования: Python ≥ 3.10, bash. Внешних зависимостей нет. Время: около
80 секунд.

```bash
bash code/run.sh
```

Скрипт (1) пересчитывает все оценки от `sources/raw/cells.csv.gz` до
`data/final/`, (2) прогоняет инварианты (в том числе независимый пересчёт
вердиктов по правилам пререгистрации и проверку эстиматора на синтетике с
известным скачком), (3) сверяет результаты с `checks/expected_results.json`
в допусках. Любое расхождение — ненулевой код выхода.

Глобальные растры (WSF, GHSL, Li et al., VIIRS VNL, GLAD — около 570 МБ без VNL)
в пакет не вложены: их адреса и sha256 — в `sources/registry_files.csv`,
загрузка и сверка — `python3 code/fetch.py --all --out <папка>`. Для полного
пересчёта таблицы ячеек из растров нужен репозиторий проекта и библиотеки
numpy, rasterio, shapely (`code/extract/seam_extract.py`, в проекте —
`SEAM_RAW=<папка> python -m etl.seam_extract`).

## Как интерпретировать

- `estimates.csv`: τ (`tau`) — скачок «сосед минус Беларусь» в самой линии;
  `se` — ошибка, кластеризованная по блокам 25×25 км; `p` — двусторонний
  p-value (нормальное приближение); `sig` = 1 при p < 0,05; `n_by`/`n_nb` —
  ячеек в окне с каждой стороны; `mean_by`/`mean_nb` — описательные средние
  в 2–10 км от линии.
- `spec`: `main` — основная спецификация (h = 25 км, треугольное ядро,
  бублик 2 км, без городов и Чернобыля); `h15`, `h50`, `uniform`,
  `with_cities` — проверки по пререгистрации; `added = 1` — проверки,
  добавленные после фиксации: `fe_subseg`, `placebo_by`/`placebo_nb`
  (ложные границы ±30 км), `donut10` (DMSP), `built_only` (исход I).
- Единицы: Δln — разность логарифмов (0,27 ≈ 27% в логарифмических пунктах);
  пашня — процентные пункты доли.
- Допуски в `expected_results.json`: ±0,001 для τ (расчёт детерминирован,
  допуск — на платформенное округление); ±0,01 для медиан H5 (%/год); 0 — для
  числа ячеек и вердиктов (1 — подтверждена, 0,5 — частично, 0 — не
  подтверждена; для H5 — с пометкой «описательно»).

## Примечания к составу

Директории `data/intermediate/` нет: конвейер пакета одношаговый
(`sources/raw/cells.csv.gz` → `data/final/`). Таблица ячеек сама по себе —
производная выжимка из растров (ARTIFACT_STANDARD.md §7).

Сырые ответы API статистических служб для официальных рядов (HTML/JSON) в
пакет не вложены: вложены собранные из них таблицы `sources/raw/units/`;
сырьё и его sha256 — в `data/raw/seam/units/raw/` репозитория проекта.

## Отклонения от пререгистрации

- Исход H1 оценён на суммарном росте WSF за 1990→2015 (`B_9015`); периоды
  1990→2000 и 2000→2015 даны отдельно.
- Разность разрывов до и после 1991 года считается на одном продукте (GHSL),
  поскольку WSF начинается с 1985 года. Сравнение сырых |τ| (как записано)
  дополнено сравнением на год: периоды 15 и 25 лет.
- Расщепление огней DMSP на 1992→2004 и 2004→2012 — разведочное (событие —
  вступление соседей в ЕС в 2004 году).
- Исключение 2,5 км вокруг факелов Нафтана и Мозырского НПЗ (36 ячеек, как в
  INF-08) добавлено при расчёте; в пререгистрации его не было.
- Проверка «выборка без исключений» (`with_cities`) добавлена при расчёте и
  снимает и городские ядра, и исключение Чернобыля (для украинского участка
  +3 737 ячеек); в пререгистрации названы только h = 15/50 км и равномерное ядро.
- H5: на уровне единиц исключены все городские единицы (города, горсоветы),
  а не только ≥ 50 тыс.; конечная точка Украины — оценка Госстата 2020 года.
- Городские ядра с обеих сторон взяты из одного источника — GeoNames
  cities15000. В пререгистрации для Беларуси указан `data.json`; единый
  источник для обеих сторон симметричнее.
- H5: вместо единого окна 1989→~2020 — окна «перепись к переписи»,
  подобранные по соседу (Литва 2001→2021 против белорусских 1999→2019,
  Польша 1988→2021 против 1989→2019 и т. д.; `WIN_NB`/`WIN_BY` в
  `code/build.py`); белорусские районы — без городов областного подчинения,
  как и у соседей.
- Проверки устойчивости, добавленные после фиксации (подучастки 1°×1°,
  ложные границы ±30 км, бублик 10 км для DMSP, контроль только застройкой
  для исхода I), помечены `added = 1` и на вердикты не влияют.
