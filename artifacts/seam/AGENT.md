# Инструкции для LLM-агента

Вы получили проверяемый пакет исследования «Шов на карте: Беларусь и соседи
по обе стороны границы» (INF-20 `seam`, v1.0.0). Ваша роль — независимый
аудитор: проверить источники, воспроизвести расчёт, найти слабые места.

## Контекст

Метод — пространственная разрывная регрессия (RDD) на пяти границах Беларуси
(PL, LT, LV, RU, UA) по ячейкам 1 км: τ = «сосед минус Беларусь» у самой
линии. Главные результаты (основная спецификация, h = 25 км):

- пашня 2003→2019: LT +13,4 п.п., LV +6,9, RU −5,1 (значимы); PL +0,3 и UA −1,9 (незначимы);
- уровень пашни 2019: RU −17,6, UA −13,4 п.п.;
- рост застройки WSF 1990→2015 — ни на одной границе не значим;
- огни 2019→2024 на украинском участке −0,27 (война);
- яркость при равной застройке (I_2019) — не значима ни на одной границе.

Вердикты: H1–H3 не подтверждены, H4 подтверждена (`data/final/seam.json`,
блок `hypotheses`). H5 (официальное население единиц, описательно) —
подтверждена: медиана годового темпа у литовских и латвийских единиц
−1,9 и −2,1 %/год против −1,4 и −1,6 у белорусских районов напротив, у
польских гмин −0,7 против −0,9, у российских районов −1,73 против −1,68
(практически одинаково), у украинских −0,85 против −1,10 (блок `units`). Правила вывода зафиксированы до расчёта —
`PREREGISTRATION.md`. Ключевые числа — `checks/expected_results.json`;
описание пакета — `manifest.json`.

## Задача 1 — проверка источников

Источники перечислены в `sources/registry.csv`, пофайловые адреса и sha256
глобальных растров — в `sources/registry_files.csv`.

1. Проверьте sha256 вложенных файлов: `sources/raw/cells.csv.gz` (строка
   `bymaps_cells`), `sources/raw/neighbors_adm0.geojson` (`geoboundaries_adm0`).
   Это же делает `checks/checksums.sha256` и инвариант
   `test_cells_source_matches_registry`.
2. Если есть сеть — `python3 code/fetch.py --source li_ntl_v10 --out /tmp/s`
   (или `--all`, ~570 МБ без VNL): скрипт скачает растры и сверит sha256.
   Несовпадение — НЕ ошибка пакета: зафиксируйте «источник изменился после
   даты обращения 2026-10-04». VIIRS VNL (Zenodo 17294744) читался по сети
   без локальной копии, sha256 для него нет — сверяйте md5 из метаданных записи.
3. Официальные ряды (H5) вложены таблицами `sources/raw/units/`: у каждой
   строки есть `source` и `definition`; источники по странам — строки
   `bymaps_data_json`, `gus_bdl`, `osp_lt`, `csp_lv`, `demoscope_1989`,
   `rosstat`, `ukrstat` реестра. Выборочно сверьте 3–5 значений с
   первоисточниками; `checks.csv` — самопроверки сборки (суммы по
   областям, сверка с Демоскопом и т. п.; статусы OK / INFO / DIFF, у каждого
   DIFF — объяснение в `comment`).
4. Без сети работайте с вложенной таблицей ячеек: она самодостаточна для
   полного воспроизведения всех оценок. Пересборка самой таблицы из растров
   (`code/extract/seam_extract.py`) требует репозитория проекта и numpy,
   rasterio, shapely — это необязательная часть аудита.

## Задача 2 — воспроизведение

```bash
bash code/run.sh          # Python >= 3.10, зависимостей нет, ~80 с
```

Результаты появятся в `data/final/`. Скрипт сам сверит их с
`checks/expected_results.json`; проверьте код выхода (0 = совпало) и
продублируйте сверку: сравните каждую метрику из
`data/final/computed_results.json` с заявленной. Дополнительно: `seam.json`
пакета должен совпасть побайтно с https://by-population-maps.vercel.app/data/seam.json
той же версии.

## Задача 3 — стресс допущений

Флаги `code/build.py` (пишите в другую папку, чтобы не перезаписать
`data/final/`): `--out DIR --h KM --donut KM --donut-dmsp KM --city-km KM
--chern-km KM --block-km KM --placebo-km KM`. Детали допущений —
`params/assumptions.yaml`, ограничения — `LIMITATIONS.md`.

1. **Ширина окна** (`--h`; в `estimates.csv` уже есть `h15`, `h50`).
   Устойчиво: пашня LT и RU, огни UA 2019→2024 значимы при 15 и 50 км.
   «Плывёт»: пашня LV при h = 15 км (p = 0,09); пашня UA становится значимо
   отрицательной при h = 50 км (−3,6 п.п.).
2. **Бублик у линии** (`--donut 5`). Проверено: пашня LT +13,0 и RU −6,5
   остаются значимыми, LV теряет значимость (p = 0,07), UA становится
   значимой (−4,6 п.п., p = 0,008) — и вердикт H2 переходит в «частично»
   (два значимо отрицательных участка из четырёх). Литовский скачок в росте
   застройки WSF становится значимым (+0,50, p = 0,02), но H1 требует трёх
   участков и остаётся не подтверждённой. Огни UA 2019→2024 −0,26 (p = 0,03).
3. **Засветка DMSP** (`spec = donut10`, `--donut-dmsp`). Огни DMSP 1992→2012
   на RU (−0,22) и UA (−0,37) значимы при любых окнах и ядрах, но при
   бублике 10 км теряют значимость; 2004→2012 на UA держится (−0,46, p = 0,015).
   Это главный хрупкий результат пакета.
4. **Кластеры** (`--block-km 50`). τ не меняются по построению; меняются
   только ошибки. Проверено: значимость главных результатов сохраняется
   (I_2019 PL p = 0,054 — на грани, но незначим).
5. **Городские ядра** (`--city-km 10`; `spec = with_cities` — без исключения).
   Проверено: оценки почти не меняются, вердикты те же.
6. **Ложные границы** (`placebo_by`/`placebo_nb`). Значимы 9 из 160 — на
   уровне случайности (5%). Но два из них важны для интерпретации: литовский
   скачок в росте застройки WSF повторяется в 30 км вглубь Литвы (+0,38,
   p = 0,04) — вероятно, пригороды Вильнюса; пашня UA — в 30 км вглубь
   Украины (−2,3 п.п., p = 0,04) — скорее градиент, чем линия.

7. **Официальные ряды (H5)**. Окна «перепись к переписи» задаются
   `WIN_NB`/`WIN_BY` в `code/build.py`. Попробуйте общее окно для всех
   (например, 1989→2019 там, где есть оба года) и посмотрите, как меняются
   медианы. Разница по России (0,05 п.п./год) мала по сравнению с различием
   определений населения (переписи наличного и постоянного населения,
   регистры, оценки на 1 января), поэтому её знак интерпретировать не стоит.

Ожидаемо устойчиво: «шов в полях» у Литвы и России, отсутствие скачка в
росте застройки и в яркости при равной застройке на большинстве участков,
падение огней на украинском участке после 2019 года. Ожидаемо «плывёт»:
пашня у Латвии и Украины, всё по DMSP.

## Формат отчёта

1. **Совпадения** — какие метрики воспроизведены (со значениями).
2. **Расхождения** — метрика, заявлено, получено, величина расхождения.
3. **Недоступные источники** — что не удалось проверить и почему.
4. **Спорные допущения** — что вы варьировали и как менялись результаты.
5. **Вердикт воспроизводимости** — воспроизводится / воспроизводится с
   оговорками / не воспроизводится.

## Границы (что пакет НЕ утверждает)

- τ — суммарный эффект ВСЕХ национальных различий (институты, политика,
  цены, правила статистики, даже то, как спутник видит разные поля). Пакет
  не приписывает скачок конкретной мере — субсидиям ЕС, сохранению колхозов
  или политике освещения.
- Застройка GHSL и WSF по построению только растёт: пакет не утверждает
  ничего о сносе, заброшенности или опустевших деревнях.
- GHS-POP — только контроль: пакет не сравнивает население по сеткам
  (входные единицы несопоставимы: BY 129 районов против PL ~2 500 гмин).
- Падение огней на украинском участке после 2022 года — война, а не
  экономическая динамика.
- Проверки, добавленные после фиксации (`added = 1`), не меняют вердикты:
  вердикты считаются только по основной спецификации.
- H5 — описательное сравнение официальных рядов без формального разрыва:
  единиц мало (у Латвии 8 против 4), определения населения и окна переписей
  у стран различаются. Пакет не утверждает, что разница в темпах — эффект
  границы.
