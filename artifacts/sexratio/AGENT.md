# Инструкция для ИИ-агента: аудит пакета INF-20 «Карта, где не хватает мужчин»

Ты работаешь с проверяемым пакетом исследования. Всё, что заявлено на
лендинге, обязано воспроизводиться отсюда одной командой.

## Быстрый старт

```bash
bash code/run.sh   # Python >= 3.10, стандартная библиотека, ~3 с, сеть не нужна
```

Ожидаемый финал: `Все 28 контрольных метрик воспроизведены в допусках.`

## Что проверять

1. **Входы**: sha256 файлов из `sources/registry.csv` против фактических.
2. **Периметры** — самое хрупкое место. В переписных файлах район *исключает*
   свой город областного подчинения, в прогнозе и `data.json` — *включает*.
   Правило сведения: `age[район] + age[город-хост]` по карте `HOSTED`.
   Проверь вручную на Полоцком районе: 103 445 + 98 926 (Новополоцк) = 202 371
   = `data.json`. Строки `c-orsha`, `c-polack` в переписных файлах — нули, это
   не ошибка: Орша и Полоцк входят в свои районы.
3. **Детерминизм**: два прогона — байт-в-байт одинаковый `sexratio.json`.
4. **Опровержение H1 своим кодом**: посчитай Спирмена между
   `min_minsk` и соотношением 25–39 за 2019 по 118 районам любым инструментом —
   должно выйти ρ ≈ −0,296. Положительного знака, который предсказывался, нет.
5. **Декомпозиция**: для любого района и когорты проверь тождество
   `observed_2019 = expected_2019 + residual` (гейт S-5).

## Стресс-тесты допущений (params/assumptions.yaml)

Перед перезапуском с правками кода удаляй байткод-кэш
(`rm -rf etl/__pycache__`).

- **Пороги onset** (`ONSET_HIGH`, `ONSET_LOW`): 120/80 вместо 115/85 —
  районов с выходом за коридор становится 27 вместо 51 (проверено);
  на H1–H4 не влияет — onset описательная метрика.
- **Выживание**: `MORTALITY_SPAN = (2014, 2014)` (одна таблица середины
  периода вместо покогортной) — H3 по-прежнему 117 районов из 118, вердикты
  H1–H4 не меняются (проверено). Это ожидаемо: смертность в 15–39 мала,
  см. LIMITATIONS.md, пункт о слабости H3.
- **Периметр H1**: пост-хок уже считает H1 на переписном периметре
  (`posthoc.census_perimeter_h1`) — знак тот же.

## Ловушки

- `min_minsk` у Минского района равен 0. Проверка `if travel.get(t)` молча
  выбросит его — в коде используется `t in travel`. Это уже было багом.
- Группа «Возраст не определен» в знаменатели не входит, но входит в
  разбиение территорий (S-3), иначе страна не сойдётся с итогом переписи.
- Блок `posthoc` — расчёты после данных. Не используй его как подтверждение
  чего-либо; он только объясняет форму опровергнутой связи.
- Шесть районов с узким возрастным мужским пиком (`narrow_age_male_spike`) —
  вероятно, население закрытых учреждений; по данным пакета это не
  проверяется, не интерпретируй их как брачный рынок.
