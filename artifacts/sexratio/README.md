# Проверяемый пакет INF-20 «Карта, где не хватает мужчин»

Соотношение полов по 17 возрастным группам и 118 районам Беларуси от переписи
2009 года до 2056-го; разделение полового разрыва на вклад смертности и вклад
не-смертностных причин (метод переписной передвижки); вердикты четырёх заранее
заданных гипотез, включая опровергнутую главную.

Лендинг: https://by-population-maps.vercel.app/research/sexratio

## Воспроизведение

```bash
bash code/run.sh   # Python >= 3.10, только стандартная библиотека, сеть не нужна
```

Ожидаемый финал: `Все 28 контрольных метрик воспроизведены в допусках.`

## Главные результаты

| Утверждение | Вердикт | Число |
|---|---|---|
| H1: мужской перевес в 25–39 растёт с удалённостью от Минска | **опровергнута** | ρ = −0,296, p = 0,0013 (знак обратный) |
| H2: в Минске и облцентрах в 25–39 женский перевес | подтверждена | Минск 94,5, Брест 87,0 мужчин на 100 женщин |
| H3: разрыв в 25–39 создан не смертностью | подтверждена (слаба по построению) | 117 из 118 районов |
| H4: в 70+ мужчин нет нигде, к 2046 разрыв сокращается | подтверждена | медиана 40,1 → 51,4 |

Страна по переписи 2019: 85,96 мужчин на 100 женщин.
