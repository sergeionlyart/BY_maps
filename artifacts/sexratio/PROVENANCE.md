# Происхождение данных и шагов

1. **Входы** (все завендорены в репозитории проекта, внешних выгрузок нет):
   переписи `age2009.csv`/`age2019.csv` (OLAP-куб Белстата F201N, построены в
   WP-F1), прогноз `forecast_age_raion_v2026_4.json` (выгрузка модели v2026.4,
   сделанная для INF-13), таблицы смертности `mortality.csv` (HMD через OWID),
   времена в пути `travel_times.csv` (INF-04), `data.json` (база проекта).
   sha256 каждого — `sources/registry.csv`.
2. **Пререгистрация** заморожена коммитом `35c1bc2` **до** первого расчёта
   половых метрик (проверяемо по истории git: файл расчёта появился позже).
3. **Расчёт** — `python -m etl.sexratio`, детерминирован, случайности нет.
4. **Поправки к гейтам** S-2, S-4, S-6 внесены датированными записями в
   пререгистрацию после первого расчёта — с причинами; гипотезы H1–H4 не
   менялись.
5. **Пост-хок** (почему H1 опровергнута) выполнен после получения данных и
   помечен так в выходном JSON, на странице и здесь.
