## 1. Исследовательский вопрос и гипотезы

Сколько работающих (по ЗАКОННОЙ границе трудоспособного возраста ГОДА `t`, не
по фиксированной константе) приходится на одного человека старше
трудоспособного возраста — по каждому из 118 районов Беларуси, 1989–2056 — и
в каком году район проходит пороги 3:1, 1,5:1 и 1:1.

Статусы гипотез ниже — фактический итог v1.0.0, сверенный с
`data/final/computed_results.json` и `web/public/data/pension.json`.

| ID | Гипотеза (замороженная формулировка) | Основной тест | Статус по данным v1.0.0 |
|---|---|---|---|
| H1 | К 2046 году >50% районов имеют `SR<1,5`; в 2009 году таких районов не было ни одного | доля `SR_2046<1,5` vs доля `SR_2009<1,5` | **Подтверждена в содержательной части, не в букве.** 2046: 69/118 (58,5%) - подтверждает первую часть. 2009: **1/118** (Кореличский район, SR=1,48), а не 0/118. Опубликовано честно как есть, см. `docs/decisions/INF-13.md` |
| H2 | Межрайонный `CV(SR)` растёт со временем | `CV(SR)_2026` vs `CV(SR)_2046` | **Подтверждена формально, но с существенной оговоркой.** `CV(SR)`: 0,1907 (2026) → 0,193 (2046) - условие опровержения `CV_2046<=CV_2026` не выполнено. НО независимая проверка тремя способами (`docs/decisions/INF-13.md`, находка B) показывает: АБСОЛЮТНЫЙ разброс СУЖАЕТСЯ - sd 0,381→0,285 (-25%), размах 2,31→1,71 (-26%). | H3 | Повышение возраста на 3 года сдвигает `crossing_year(1,5)` на 8-12 лет, не отменяя переход ни в одном районе, где он наступает до 2056 при as_is | среднее/медиана `policy_delta`; доля районов с «отменённым» переходом | **Опровергнута в части «не отменяет».** Средний сдвиг 9,24 года (медиана 9,0) - ВНУТРИ интервала [8,12] - но у **27 из 93** районов (29%), проходящих порог при as_is до 2056 года, переход при графике 65/60 не наступает в пределах горизонта модели (2056) - т.е. «отменяется» в пределах прогнозного окна. Ни одна гипотеза не подтвердилась строго «как заморожено»: во всех трёх
случаях реальный расчёт нашёл пограничные исключения (Кореличский район для

ожидаемо при 118 независимых территориях и порогах, замороженных ДО расчёта
(раздел 11 ТЗ запрещает подгонку постфактум) - несовпадение публикуется, а не
сглаживается.

## 2. Единицы анализа и выборка

- **Территория × год** — 118 районов + страна (BY), 1989–2056 (национальный
  ряд включает советские переписи 1989/1999; районный - только 2009+, где
  есть районная возрастная структура).
- **Территория × год × сценарий × стартовый ряд** — прогнозная часть
  (2031–2056): 3 сценария (`base`, `optimistic`, `negative`) × 2 стартовых
  ряда (`official`, `adjusted`) = 6 комбинаций, `series_keys` в
  `pension.json`.
- **Территория × год × вариант политики** — `as_is` (действующий график),
  `65_60`, `67_62` (гипотетические графики пенсионного возраста,
  применяются только с 2026 года).

Выборка: 118 районов реестра проекта (`etl/registry.py`) + страна. Периметр
района-хоста включает город областного подчинения (карта `HOSTED` в
`etl/forecast/sub.py`) - как в остальных прогнозных пакетах проекта.

## 4. Формулы (Приложение А ТЗ)

Обозначения: `P[a..b]` — население в возрасте от `a` до `b` лет включительно
(равномерное распределение внутри 5-летних групп при дробных границах);
`A(t)` — законная граница трудоспособности года `t` (по полу, из
`retirement_age.csv` до 2022 года, далее — по варианту политики).

### 4.1. Коэффициент поддержки (SR)

```
SR(t) = P[16 .. A(t)-1] / P[>=A(t)]
```

Суммируется по обоим полам: работающее население (от 16 лет до своей
законной границы, раздельно по полу) делится на население старше границы
(тоже раздельно по полу, затем сложено).

### 4.2. Коэффициент демографической нагрузки (TDR)

```
TDR(t) = (P[0..15] + P[>=A(t)]) / P[16 .. A(t)-1]
```

Дети (0-15) плюс люди старше трудоспособного возраста, делённые на
работающее население. `TDR ≈ 1/SR` с поправкой на детей.

### 4.3. Год перехода порога (crossing_year)

Первый год, когда `SR(t) < θ`, для `θ ∈ {2,0; 1,5; 1,0}`, с линейной
интерполяцией между соседними известными узлами ряда:

```python
def crossing_year(sr_by_year, threshold):
    years = sorted(y for y, v in sr_by_year.items() if v is not None)
    if sr_by_year[years[0]] < threshold:
        return years[0]
    for y0, y1 in zip(years, years[1:]):
        v0, v1 = sr_by_year[y0], sr_by_year[y1]
        if v0 >= threshold > v1:
            frac = (v0 - threshold) / (v0 - v1)
            return round(y0 + frac * (y1 - y0))
    return None
```

### 4.4. Условная денежная арифметика (CG) — MODEL целиком

```
CG(t) = (E(t) * W * τ) / (R(t) * B)
```

- `E(t)` — оценённая занятость района в году `t`: ставка занятости 2024 года
  (последнее наблюдение) × прогнозное трудоспособное население `P[16..A(t)-1]`;
- `W` — средняя зарплата района, зафиксирована на последнем наблюдаемом годе
  (2025) для ВСЕХ прогнозных лет — изолирует демографический эффект, НЕ
  прогнозирует экономику (см. LIMITATIONS.md, п. d);
- `τ = 0,29` — ставка пенсионного страхования (28% работодатель + 1%
  работник, ст.5 закона №118-З); НЕ включает отдельные 6% социального
  страхования (иное назначение фонда, см. `data/raw/pension/registry.csv`);
- `R(t)` — оценённое число получателей пенсий района: `P[>=A(t)] * k_oblast`,
  где `k_oblast` — коэффициент охвата области (получатели / население
  старше границы, якорь — перепись 2019 года), перенесённый на все годы без
  изменения;
- `B` — средняя пенсия области, зафиксирована на последнем наблюдаемом годе
  (2025) для всех прогнозных лет, как и `W`.

`CG < 1` — оценённые отчисления не покрывают оценённые выплаты; `CG >= 1` —
покрывают. Это **межрайонный сравнительный индекс**, не факт: ни один из
пяти компонентов формулы не наблюдается на уровне района напрямую (см.
claims.yaml C-006, LIMITATIONS.md).

**Важно (независимо подтверждено проверяющим-скептиком, находка C):** для
конкретного района `W`, `τ`, `k_oblast` и `B` не зависят от года, а `E(t)`
и `R(t)` оба линейно пропорциональны возрастной структуре района через ту
же функцию `A(t)`, что и сам SR. Формально `CG(t) = K_r · SR(t)`, где
`K_r` — константа района. CG **не** является вторым, независимым от SR
подтверждением демографического тренда — это тот же коэффициент поддержки,
пересчитанный в условные деньги при текущем экономическом масштабе района
(см. LIMITATIONS.md, п. a).

### 4.5. Политический сдвиг (policy_delta)

```
policy_delta(θ, policy) = crossing_year_policy(θ) − crossing_year_as_is(θ)
```

Гипотетические графики (`65_60`: 65 муж./60 жен.; `67_62`: 67 муж./62 жен.)
применяются только с 2026 года включительно (`POLICY_APPLIES_FROM`) — задним
числом закон не переписывается: для лет до 2026 всегда используется
`as_is` независимо от выбранного варианта.

## 5. Дробное деление возрастных групп

Входные данные — 5-летние возрастные группы; законная граница
трудоспособности не кратна пяти годам (63/58, 65/60, 67/62). Внутри группы
население распределяется РАВНОМЕРНО:

```python
def pop_below(struct_sex, cutoff):
    for lo, hi in group_bounds:
        if cutoff <= lo: continue
        elif cutoff >= hi: total += v
        else: total += v * (cutoff - lo) / (hi - lo)
```

Стандартное демографическое допущение; альтернатива (округление границы до
кратных пяти лет) искажала бы историю при переходах 60→63 (муж.) и 55→58
(жен.).

## 7. Обратный бэктест (G-3): замена метода

Пререгистрация ожидала стандартный бэктест «откалибровать на одном окне,
проверить на другом» — но районного разреза переписи-1999 не существует
(источник этого уровня детализации не оцифрован). Вместо использования
CCR-модели субрегионального прогноза (`etl/forecast/sub.py`), откалиброванной
ИМЕННО на паре 2009-2019 (что сделало бы бэктест на том же окне
самоисполняющимся - модель бы «предсказывала» данные, на которых сама
обучена), применена **независимая от неё** проекция «только дожитие»:

- национальная таблица смертности HMD-2018 (та же, что использует и
  основной движок, но БЕЗ калибровки к 2019 года и БЕЗ миграции);
- child-woman ratio (CWR) из САМОГО 2009 года (не из 2019, куда целится
  прогноз);
- когорта 2009 года переносится на 2019 год через два шага 5-летнего
  дожития.

Результат: MAPE модели 8,86% против MAPE наивного прогноза (SR заморожен на
уровне 2009 года) 13,93% — модель точнее наивного (условие 1 выполнено), но
доля районов с верно предсказанным ЗНАКОМ изменения — 73,7%, ниже
требуемых 80% (условие 2 не выполнено). Итог: гейт НЕ пройден, поэтому
`crossing_year` района публикуется тремя интервальными категориями
(«до 2035», «2035-2045», «после 2045»), а не точным годом. Обоснование
замены метода и её ограничений — `docs/decisions/INF-13.md`.

**Оговорка проверяющего-скептика (находка E):** проекция «только дожитие»
НЕ включает миграцию — в отличие от боевой CCR-модели (`etl/forecast/sub.py`),
которая неявно учитывает миграцию через эмпирический коэффициент когортного
изменения 2009→2019. G-3, таким образом, тестирует более СЛАБЫЙ прокси-метод,
а не саму боевую модель — реальная точность боевой модели (используемой для
прогноза после 2026 года) может быть выше, чем показывает этот
консервативный тест. Непройденный результат G-3 при этом остаётся в силе.

## 8. Блок метода (восемь обязательных полей)

1. **Исследовательский вопрос.** Сколько работающих по законной границе года
   `t` приходится на одного человека старше трудоспособного возраста в
   каждом из 118 районов Беларуси, 1989-2056, и когда район проходит пороги
   3:1/1,5:1/1:1?
2. **Единица анализа.** Территория (118 районов + страна) × год ×
   (сценарий прогноза × стартовый ряд, для 2031+) × вариант политики
   пенсионного возраста.
3. **Источники.** Переписи 2009/2019, текущая оценка 2025/2026, прогноз
   v2026.4 (CCMPP/Гамильтон-Перри), законный график пенсионного возраста
   (Указ №137/2016), зарплата и занятость районов (INF-03/08, Белстат),
   получатели пенсий и средняя пенсия по областям (Белстат), времена в пути
   до Минска (INF-04), UN WPP 2024 (сверка).
4. **Преобразования.** Дробное деление 5-летних возрастных групп по
   погодовой законной границе; линейная интерполяция crossing_year между
   узлами; проекция «только дожитие» для бэктеста G-3; оценка получателей
   пенсий района через областной коэффициент охвата k_oblast (якорь 2019).
5. **Показатели.** `SR = P[16..A(t)-1]/P[>=A(t)]`; `TDR = (P[0..15]+P[>=A(t)])/P[16..A(t)-1]`;
   `crossing_year(θ)`; `CG = (E·W·τ)/(R·B)`; `policy_delta`.
6. **Допущения.** Равномерное деление возрастных групп; k_oblast постоянен во
   времени; зарплата и пенсия заморожены на последнем наблюдении;
   ставка занятости 2024 года перенесена на прогноз; гипотетические
   графики пенсионного возраста применяются только с 2026 года.
7. **Проверки.** Гейты G1-G7 (см. VALIDATION.md); инварианты
   (`checks/tests/test_invariants.py`): диапазоны SR/TDR, монотонность
   порогов crossing_year, согласованность подавления CG, интервализация
   crossing_year у ВСЕХ районов (следствие непройденной G-3), запрет
   формулировки CG как самостоятельного районного финансового баланса.
8. **Ограничения.** CG - синтетический индекс, не факт; получатели пенсий
   района не наблюдаются; занятость и зарплата 2031+ - перенос, не прогноз
   экономики; crossing_year района - интервал, не дата; CG скрыт у 5 районов
   рядом с Минском; неучтённая эмиграция 2020+ отражена двумя параллельными
   стартовыми рядами. Полный разбор - LIMITATIONS.md.
